# Aprendiendo-programacion

Repo donde vuelvo a aprender a programar, con Claude como profesor.
No es un repo para producir software rápido: es para que yo entienda lo que escribo.

## Mapa

| Carpeta | Qué es | Quién escribe |
|---|---|---|
| `Informacion/` | Contexto y memoria del proyecto. Quién soy, el método, la bitácora, dónde estamos. | Claude |
| `Referencia/` | Chuletas de sintaxis. Se consultan siempre, sin culpa. | Claude |
| `Clases/` | Una carpeta por clase: enunciado, mi práctica, y la revisión. | Enunciado y revisión: Claude. Práctica: **yo** |
| `Asistente/` | El proyecto real. El código que queda. | **Yo** |

`CLAUDE.md` (raíz) es lo que lee Claude automáticamente al abrir el repo, y lo manda
a leer `Informacion/`. Sin ese archivo, el resto es decoración.
